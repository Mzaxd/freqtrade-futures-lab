## 0. 预注册（回测开始前冻结，2026-09-14）

### 0.1 预注册 kill 标准（逐字冻结，跑完不许改）

在 **2023 段（2023-01-01 → 2023-12-31 切片）** 上，对预注册阈值网格 {0.02, 0.03, 0.05} 中的每一档分别评估；
**任何一档同时满足以下全部 5 条 → "条件存活"；全部档位中无一满足 → "判灭"**：

1. **K1 收益**：2023 段总收益 > 0（正）；
2. **K2 盈利因子**：PF ≥ 1.0；
3. **K3 样本量**：2023 段交易数 ≥ 100；
4. **K4 费率墙**：平均单笔盈亏 > +0.10%（双边手续费 0.05%×2 = 0.1%，必须毛过费率墙）；
5. **K5 非少交易伪改善**：以 thr=0.02（最多交易档）为参照，若最优档收益更高，则其**平均单笔盈亏也必须比 thr=0.02 档更高**（即高阈值选出了"更好的交易"而不只是"更少的交易"；对照 S4 阈值 0.02→0.05 时 PF 原地踏步的灭因）。

判灭的充分条件（任一即灭，无需看其余）：2023 段最优档 PF < 1.0 **或** 收益 < -10% **或** K5 失败。

附带披露义务：无论结果如何，报告必须给出 (a) 全部 3 档的全数字（不许只挑好档）；(b) 2021-22 发展段与 2023 段分开；(c) 交易数与均利的对照表（K5 的证据）。

### 0.2 预注册设计（冻结，冒烟测试只允许修 bug 不允许改参数）

- **数据**：12 币 1h（仓库既有 feather，2020-09 → 2026-09；评估只用 ≤2023-12-31）。
- **特征**（11 个，全部因果滚动窗口、全部无量纲/era-invariant——吸取 regime_detector iter-2 与 S4 教训）：
  `ret_24h/ret_72h/ret_168h`（多周期对数收益）、`rvol_12h/rvol_48h`（已实现波动）、
  `mom_z_72h`（72h 动量 t 化：mom / (rvol·√72)，regime_detector 思想）、
  `atr_ratio`（ATR14/其 720h 滚动中位，"ATR 比"）、`dk_vol_ratio`（rvol_12h/其 720h 滚动中位，"DK 波动比"）、
  `funding_rate`（因果已结算资金费，opt_common.attach_funding 只读复用；首结算前 fillna(0)）、
  `funding_ma3d`（费率 72h 均值）、`volume_rel_24h`（量/24h 均量）。
- **标签**：三重屏障二分类（字符串类 "up"/"dn"）：屏障 = close_t ± 2×ATR14_t，48h 超时；
  同 K 线双触按该 K 线收盘方向裁决；超时按 t+48 收盘方向裁决；ATR/未来数据缺失 → NaN（FreqAI 丢弃）。
  语义：P(up) = "在 48h 内先触 +2×ATR 而非 -2×ATR" 的概率。
- **模型**：LightGBMClassifier（freqtrade 内置），预注册超参：n_estimators=200, learning_rate=0.05,
  num_leaves=15, min_child_samples=25；data_split test_size=0.33、shuffle=false（时序内验证集做早停评估）；
  weight_factor=0.9（温和新近加权）；include_shifted_candles=0；DI_threshold=0（关 DI，保留 NaN 剔除）。
- **净化（purge）**：`feature_parameters.buffer_train_data_candles = 48`（= 标签视界）。语义（2026.8 源码
  `FreqaiDataKitchen.buffer_timerange`，见 §2）：训练窗 [T, T+30d) 在**标签已算好之后**两端各裁 48 根 →
  实际训练行 [T+48h, T+30d-48h)，其标签最多用到 T+30d 之前的 K 线，与预测窗 [T+30d, T+37d) **零重叠**；
  同时裁掉了训练切片尾部的标签 NaN 行。注意：FreqAI 无原生 "embargo" 参数（`purge_old_models` 只是删旧
  模型文件，`expiry_hours`/live_retrain_hours 只管 live 重训节奏）；本设计用 buffer 实现标签视界净化，
  串行相关层面的额外 embargo 不做（滚动特征模型固有，披露于此）。
- **walk-forward**：train_period_days=30，backtest_period_days=7（每 7d 重训），
  20210101-20240101 一次跑完；12 币 MOT4（fee 0.05%/边，isolated futures，可做空）。
- **交易逻辑（镜像三重屏障）**：入场 P(up) ≥ 0.5+thr（多）/ ≤ 0.5-thr（空）且 do_predict==1；
  止损 = 入场信号 K 线的 -2×ATR14（custom_stoploss 锁定价位，回测按触价成交）；
  止盈 = +2×ATR14（custom_exit，**次 K 线开盘成交**——回测 custom_exit 只能在 K 线开盘时评估，
  触障后若回撤会错过，系统性保守偏差，披露）；48h 超时强平（custom_exit，与标签语义严格对齐）。
  无信号反转退出、无 minimal_roi、无追踪止损——盈亏归因干净。
- **阈值网格**：thr ∈ {0.02, 0.03, 0.05}，即 P(up) ≥ {0.52, 0.53, 0.55}（多），对称做空。
  三档共用同一 identifier 的预测缓存（阈值只作用于预测之后的入场逻辑，模型与预测逐位相同——
  S4 已验证的等价加速，zip 内 freqai_identifier 三重核对）。跑完不许加档。
- **冒烟测试**：2023-01-01 → 2023-02-01，仅验证机制（列名/空值/成交/退出路径），不改任何预注册参数。

## 2. FreqAI 2026.8 purge/embargo 语义确认（源码级）

- **`feature_parameters.buffer_train_data_candles`**（本设计 = 48）：`FreqAIDataKitchen.buffer_timerange`（data_kitchen.py L977-998）在**标签已算好之后**把训练窗 [T, T+30d) 两端各裁 N 根 → 实际训练行 [T+48h, T+30d-48h)。其标签最多用到 T+30d-1h 的 K 线，与预测窗 [T+30d, T+37d) **零重叠**（这正是三重屏障的净化要求，48 = 标签视界）；顺带裁掉了训练切片尾部的标签 NaN 行。**这就是本沙盒用的 purge 机制；任务书里的 "exp_buff" 即指此参数。**
- **`purge_old_models`**（=2）：只删旧模型**文件**（data_drawer.py L547），与数据净化无关，且 backtest 模式不执行。
- **无原生 embargo**：不存在串行相关层面的额外间隔参数。滚动特征与相邻样本的相关性是 walk-forward 固有，本报告如实披露不额外处理。
- `data_split_parameters.shuffle=false` + test_size=0.33：训练窗内**时间序**最后 33% 作早停评估集，其标签信息严格早于净化边界，无泄漏。
- 分类器管线（BaseClassifierModel.predict）：策略 df 同时拿到 `&-标签`（类别）+ **以类别名命名的概率列**（本例 "up"/"dn"）；标签须为字符串 dtype 才能被 `get_unique_classes_from_labels` 注册。

| 阈值的作用 | 减亏 29pp（少交易） | 笔数 -86% 减亏 | **几乎无效**（笔数仅 -4.3%，概率分布挤在死区） |
| 特征 OOS 信息 | 未测 | 份额 2.76% | **permutation ≈ 0** |

三次证伪的共同点：**改善永远来自少交易，从不来自更好的交易**；模型从未产生过可交易的 OOS 方向边际。本设计把方法论短板补齐（净化、正经标签、1h 降换手、无量纲特征）后，结果反而更差——说明 30d 训练窗 × 48h 标签视界的**有效样本只有 ~15 个独立事件**（30d/2d），模型学到的是训练窗噪声（冒烟时未正则化版本训练准确率 88.5%），OOS 塌缩成带轻微反向的先验。

灭因排序（按证据强度）：
1. **OOS 零判别力**（校准表 + permutation 双证）；入场带轻度反向选择（48% vs 基准 49.2%）。
2. **TP/SL 成交语义不对称**：SL 触价成交 vs TP 次开盘成交，标签胜率 48% 被吃成交易胜率 37%（-11pp），跨过 45.1% 盈亏平衡线的方向是错的。
3. 训练窗/标签视界失配（30d/48h ≈ 15 个独立事件）——方法论层面的先天不足， hindsight 诊断。
4. **不是费率**（0.10pp/笔，仅占均笔亏损 29%；S4 的费率墙灭因在这里不成立）。

## 5. 局限与诚实披露

1. **预注册纪律**：kill 标准、阈值网格、特征集在第一次全量回测前冻结并写入 §0，全程未改；冒烟驱动的 4 处变更全部记录于 §0.3（机制 bug 3 处 + 1 处依据训练窗诊断的超参正则化，未看任何 VAL 盈亏）。预注册未写明破产时 2023 段口径 → 双口径都报告，判定不受影响。
2. **TaskStop 事故**：被杀进程未死透，废 zip 覆盖过正常 t03 zip；通过退出结构审计发现（2187 笔 48h 超时 + 1 笔 -99% = 特征性指纹），正常 zip 已重生成并与覆盖前对话记录数字逐位一致（5080 笔/PF 0.761），废 zip 留档为消融证据。
3. TP 次开盘成交是系统性保守偏差（真实交易同样存在滑点，方向一致但幅度不同）；48h 超时从成交时刻计，与标签从信号 K 线收盘计有 ≤1 根 K 线的近似。
4. 单种子单超参集合，无重抽样置信区间；Sharpe/Sortino 来自回测日度钱包序列，破产段失真。
5. 相位噪声（S4 量级 ±5pp）相对 -93% 的结果无判定影响。
6. 模型产物 217MB 留在 `user_data/models/fai_v1/`（FreqAI 固定路径，全为新增文件），供复现/复核；2024-01-01 之后的数据从未进入任何评估。
7. OI/基差特征放弃（§0.4）：Binance `/futures/data/*` 端点实测仅保留最近 ~30 天，2021-2023 逐时历史不可得，不编造。

## 6. 结论

**[假设生成] 判灭。** 用净化 walk-forward + 三重屏障标签 + 11 个因果无量纲特征 + LightGBM 分类器重试 ML 线，2023 段三档预注册阈值全灭（PF 0.63-0.67，-93%~-95%），一体化跑第一年破产。信息量诊断（校准 + permutation）显示模型 OOS 判别力≈0；退出实现的不对称把中性入场做成深亏。三次证伪（模板/S4/本设计）覆盖了"费率墙、模板特征贫乏、方法不严谨"三种灭因假设后均以更严方法复灭——**在本实验室的数据与信号族里，FreqAI/GBM 独立进出场这条线应当归档**；若未来有新数据再验证，唯一值得带的行囊是 §1.5/§4 的两条工程教训（TP 用 custom_roi、训练窗 ≥ 20-30× 标签视界）。
