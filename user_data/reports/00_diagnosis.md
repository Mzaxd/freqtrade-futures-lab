## 2. 根因分析（按证据强度排序）

### 根因 1（架构性，主因）：单一逻辑硬扛所有市场状态
分段测试铁证：2021 牛 +41.7%、2021-22 熊 +7.5%、**2023 震荡 +0.2%**。趋势策略在震荡市零产出还支付成本；而 2023 全年整段浪费（VAL Sharpe=0.00）。策略没有"现在是什么市"的概念，无法在不适配状态下降仓/停手。→ **正是本轮"状态识别 + 路由"架构要解决的问题。**

### 根因 2（成本结构）：1h 周期被双边 taker+资金费吞噬
1h 家族三策略全亏（v1 -30.8%/v2 -79.9%/v3 -22.7%），v2 897 笔交易仅手续费就 929 USDT（初始资金 10k）。换 4h 后费用从 758 降至 109 USDT，IS 即从 -30.8% 修复到 -6.2%。→ 本轮子策略默认 4h（均值回归子策略 1h，但必须证明其单笔边际 > 0.12% 成本线，否则降频）。

### 根因 3（统计性）：冻结参数落在高原分布的幸运上沿
Hyperopt 高原：187/250 epochs 盈利，但**盈利 epochs 收益中位数仅 +4~8%**，冻结默认值跑出 +52.2% 属高原右尾。压力测试（±10-20% 扰动后 +5~24%）印证中心期望单薄。→ 本轮选参以"高原中位数 + 扰动稳健性"为准，明确不以单点最优为目标。

### 根因 4（结构性）：优势集中于高波动资产
分交易对（2021-23）：BTC +1.8%（≈0）、ETH +11.5%、SOL +35.8%。BTC 单独部署无边际。→ 本轮要求三对各自过基本门槛（6.2），路由层需按状态×资产条件分配。

### 排除项（不是失败原因）
- **未来函数**：freqtrade `lookahead-analysis` 判定 has_bias=No（0/20 信号有偏）；Donchian 通道 shift(1)。
- **数据问题**：缺失/重复/空值全 0；funding 与官方归档 0 差异。
- **风控失效**：0 爆仓 0 强平；单笔风险恒 1%。
- **幸存者偏差选币**：BTC/ETH/SOL 按市值预选。

上一轮在参数冻结后查看过 **2024-01→2026-09 聚合样本外结果一次**。按本轮第 4.1 条（样本外用过即作废），裁定：

## 4. 对本轮架构的直接约束（由根因导出）

1. 震荡状态必须有独立收益来源（均值回归），否则路由只是"少亏"不是"增益"；
2. 子策略频率/成本预算：单笔预期毛边际必须 > 2×taker+滑点 ≈ 0.12%；
3. 选参只用 IS 高原中位数；VAL 只做选择与验证，不做参数搜索；
4. 状态识别层先独立证明（准确率>随机、切换滞后<5根K线），再接入路由；
5. 每轮迭代一个假设、可回滚、git 留痕。
