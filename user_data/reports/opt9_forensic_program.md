## 0. 程序中发现并修复的 OPT8 潜伏实盘 bug（重要性高于优化本身）

**现象**：本机复现基准时，OPT8（= run-2 在跑的 live-fix 版）回测 +1170.8%，OPT4 +1464.1%，
分叉全部来自 15 笔 `trailing_stop_loss` 出场——全是被提前砍掉的大赢单。

**根因链**：
1. freqtrade ≥2024 回测中 `get_analyzed_dataframe` 只返回**最近 1000 根**滑动窗口
   （`df.iloc[max(0, max_index-1000):max_index]`）；
2. 1h 周期下 1000 根 ≈ 42 天；持仓超过后，入场 K 线滑出窗口；
3. OPT8 `_signal_candle` 返回 -1 → 走 `fallback_stop_ratio=-0.10`；
4. **该裸比例被 `adjust_stop_loss` 按当前价解释** → 止损=当前价×0.95 且棘轮只紧不松
   → 意外的 5% 追踪止损，只命中长持仓趋势赢单（IS 复现：利润 -20%，15 笔肥尾被截）。

**对 run-2 的影响**：run-2 自 2026-09-25 启动，任何交易持仓跨过 ~1000 小时（42 天）
即触发。当前无人中招不代表安全——趋势单平均持仓 18-45 天，60 天时间止损上限之内
必然出现 >42 天持仓。

**修复**（`OPT8b_VolatilitySystem.py`，run-3 热修复候选）：
1. 入场 ATR 首次调用时查一次并 `set_custom_data` 缓存到 trade（live 持久化，重启不丢）；
2. fallback 改 `stoploss_from_open`（相对**开仓价**的静态紧止损——OPT8 注释的本意）。
   回测等价性已验证：OPT8b 在 12p IS **逐笔精确复现** OPT4（436 笔 / +1464.09% / DD 15.95%）。

### P1 证伪的结构性教训
7/8 个取证 agent 都指向"浮盈回吐真空"（静态上界 +34~62k），但 OHLC 极值模拟无法判定
**路径顺序**：真实回测里大量赢单在主升前先走过 ≥1.5R 中间峰、再深回踩入场区——地板
把它们全部扫掉（2023H1 窗 +17.5k → +1.4k）。肥尾是靠承受深回撤买来的，任何按价格
行程武装的地板都会截断它。两个预注册点同向惨败，方向永久关闭（除非有结构性不同的
武装信号，如 funding/时间，未在本程序授权内）。

### P2 胜出的机制解释
maxDD 15.92% 的解剖：2023 年"单边止损簇 → 同向再入 → 再簇"7 连链。单边簇后 72h
**同向**再入场 12 笔净 -2,516，**反向** 31 笔净 +53,758（强不对称）。熔断只砍同向、
只砍簇后 48h、由自身止损事件触发（非事前指标）。与已证伪清单的正交性：phase4
cooldown 是逐币/方向盲/常驻；phase6 CC1a/b 是全局帽且被挡集合净正（拒单=删赢家）；
P2 被挡集合仅 11 笔、净 +4.6k（保险费），换来 DD -5.85pp。
Calmar（利润/MaxDD）：91.8 → 140.4（**+53%**）。

## 组合层复验（方向 2：OPT9 替换 sleeve A）

方法（披露）：月度闭仓聚合近似——各 sleeve 按自身交易自复利（10k 起），月收益 =
当月盈亏/月初权益；组合月收益 = Σ权重×各 sleeve 月收益；36 个月（2021-23）。口径为
近似，**A1-vs-A2 的差值才是交付物**。脚本 `scripts/opt9_combo.py`。

实际数字（本机重跑 sleeve：B=OPT2_MomRegime15mLb21 12 币 MOT3 111 笔 +1421.4%；
N=OPT7_NFILite 12 币 MOT6 303 笔 +58.5%，2021-23）：

```
sleeve 月度口径:   A1=OPT4  +1042.1%/DD 12.98%/Calmar  9.65
                  A2=OPT9  +1008.3%/DD 12.06%/Calmar 10.19
corr: A1×B=0.100  A1×N=0.268  A2×B=0.081  A2×N=0.286  B×N=0.141
组合               A1 版                        A2 版（OPT9）
  alone            +1042.1% / 12.98% /  9.65    +1008.3% / 12.06% / 10.19
  A+B 50/50        +1558.3% / 10.07% / 15.39    +1536.2% /  8.65% / 17.78
  A+B+N 40/40/20   +1003.0% /  7.12% / 17.21    +989.0%  /  6.30% / 19.31
```

**结论：换入 OPT9 后组合数学全面改善**（40/40/20：DD 7.12→6.30%，Calmar 17.2→19.3；
corr 结构保持低相关）。与 phase7 结论同向：**部署建议 A+B+NFI = 40/40/20，A 腿用
OPT9。** 披露：月度聚合近似口径；NFI-Lite 本机跑的窗口是 2021-23（phase7 为 21-24），
笔数 303 vs 417 系窗口差异，corr 结论不受影响。

## 实现事故记录（诚实账本）
