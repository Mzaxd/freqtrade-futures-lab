# 02 路由回测与增益测试报告

> 候选：`RegimeRouter`（iter-13 冻结）。三层：规则检测器 v3（mom_z ±1.25 + ATR 分位混乱层 + 2 根驻留平滑，仅 IS 定阈值）→ 逆向否决制路由 + 状态分级仓位 → 三个 4h 子策略（EMA 趋势多/EMA 趋势空/布林 z 拒绝均值回归）。
> 窗口：IS 2021-01→2022-12（开发）；VAL 2023-01→2024-12（增益测试）；OOS 2025-01→2026-09（未使用，另见最终报告）。
> 成本：taker 0.05% 双边 + 真实资金费率；杠杆 3x 逐仓；风险预算 1%/0.7%/0.5%（多/空/MR），震荡档 ×0.5；单笔 ATR 止损；无加仓；0 爆仓。

## 4. 架构说明

- 检测器：`regime_detector.py`（独立模块）+ `regime_loader.py`（装载）；因果性：全部滚动窗口 + 前向滤波 + 驻留平滑；阈值仅 IS 拟合/选定。
- 路由器：`regime_router.py`；子策略独立可运行版：`sub_standalone.py`（增益对照用）；历史版本 `sub_momentum.py`/`sub_trendshort.py`/`sub_meanrev.py`（iter-4 基线，保留存档）。
- 退出体系：每笔 ATR 初始止损（多空 3.0×ATR4h，MR 2.0 锚定无追踪）+ 趋势腿 4.2×ATR 追踪 + 信号退出（EMA 反交/中轨回穿）+ 逆向状态退出 + 时间止损（28/21/7 天）+ 灾难止损 -0.30。
- 复现：`make` 目标见 README；单命令 `./scripts/run_backtest.sh RegimeRouter 20230101-20250101 <tag>`。

## 5. 已知局限

- WF 为冻结参数版（无逐窗重拟合必要：规则检测器无可拟合参数除 IS 阈值，子策略参数为先验值）——见 WF 报告；
- 检测器标签准确率 58-59%（未达 60% 三分类线），增益主要来自**逆向否决**（避开高确定性的坏状态）而非精准择时——这解释了为何增益集中在回撤与 Sharpe 而非绝对收益；
- 空头腿尚未在任何窗口证明正贡献。
