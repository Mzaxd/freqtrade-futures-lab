## 1. 总裁决:**六变体全部在 IS 证伪;2026 增厚 = 0;本线诚实失败**

任务目标(2026 组合 +7% → ≥+15%,组合红线 ≥−20%)在本线约束(A 袖减风险 overlay、2023 代价 ≤3pp、2022 不变差)下**未达成**。所有预注册变体死于同一个结构性事实(§3):

> **A 袖的利润高度集中在"回撤后的恢复窗口"(post-dip recovery)。任何"出血期减敞口"的机制,都在卖出恢复——而恢复与出血在发生时不可区分。**

这是 research_chop"事前不可识别性"结论第三次独立确认,且从**入场日选择**层面扩展到了**敞口规模(sizing)**层面:不仅"哪笔交易"不可事前识别,"出血期该减多少仓"同样不可——减仓动作本身有约 **19:1** 的逆价比(见 §3.1)。

## 3. 机制解剖:为什么 19:1

A 袖年化极高(21-23 年均 +134%),其利润引擎 = "深度回撤中满仓吃 V 型恢复"(2023-09-28→11-08 的 42 天里:回撤加深的同时在谷底满风险入场,12 月一举收复并新高)。DD-band 一旦武装,恰好把谷底入场的风险砍半——**卖掉了引擎本身**。2026 型出血(2-8 月无恢复)与 2023 型回撤(9-11 月深 V)在武装时刻(跌破 0.92 峰)状态完全相同,区分只能事后。这不是阈值问题:0.92/0.97/0.95 臂、0.5/0.65 剂量、RV 冻结/自适应、缩放/暂停,六个预注册点全部撞同一堵墙。叠加既有事实(每个 risk_pct 拨盘 CAGR 等比缩,chop R3 救回 ~2pp),**A 袖上的"出血期减风险"路线在本约束下可宣布关闭**。

## 4. 与已有熔断(P2)的关系

P2 单边簇熔断(24h 内 ≥2 同向止损 → 48h 拒同向新仓)与本线互补且共存的假设被验证为真:六变体全部继承 P2 运行,无冲突。但两者面对的出血不同:P2 管"簇内 48 小时"的再入场(短、密、自指信号),本线试的是"月级持续出血"的整体敞口(长、缓、无自指信号可用)——后者被证明没有可用的因果状态变量:DD 状态 = 卖恢复,RV 状态 = 卖高波盈利窗。

## 6. 诚实性披露

1. **失败是产出**:本线关闭的是"IS 内可验证的减风险 overlay"路线;因无路线过 IS 门,**24-26 holdout 一次未烧**(对后续研究线是净节省)。
2. 多重检验:6 变体 + 2 剂量点全灭,不存在挑选;若某变体以 0.8pp 之差擦线过关(如 V2 若门宽 1pp),其单发结论也会因机制近惰性而大概率无 2026 改善——即"过门失败"与"惰性无改善"在此处指向同一结论。
3. 事后考虑并算术否决(未烧预算):崩盘期撤除 recycle 放大(×1.21→1.0,剂量≈0.83)→ 插值 2023 代价 ≈15pp(超 3pp 预算 5 倍),且 2026 出血仅减 ~17% → 组合 2026 约 +9~10%,低于 +15% 目标。两条标准都不过,不值得一次回测。
4. IS 无 2026 型样本的固有局限(pre_reg §6.1 已预声明):本线只能证伪"IS 代价约束内"的 overlay;理论上存在"IS 惰性、2026 恰好激活"的彩票型状态,但那不是机制,不构成研究产出。
5. 2021-23 RV 阈值(0.850/365d-p85)取自 IS 样本(diag_rv_is.py / rv_is_stats.json),零 24-26 调参。
6. 沉默失败排除:各变体运行结果与基线偏离(2021/2022/2023 年均有),证明 overlay 实际武装过;RV 状态因果性经单测(日内不变、只用完全收盘日、时区处理)。
7. phase7 turbulent-pause 曾在新币宇宙(DD 42% 语境)有效——与本结果不矛盾:那是陌生宇宙的止损风暴,这是本宇宙(3 币+recycle)的高频 V 型恢复引擎;同一机制在不同 edge 密度下代价完全不同。
