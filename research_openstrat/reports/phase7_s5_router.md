## 2. Router 2.0 设计（OPT7_Router20.py，fork 思路，骨架保留）

`OPT7_Router20Base(RegimeRouter, OPT4_VolatilitySystem)`：骨架 = regime 序列（regimes_opt7）+ 槽位路由 + risk_scale + turbulent(3)/未知(−1) 停开仓 + per-tag 预算 + 全部离场走 custom_exit（exit 列留空）。腿替换：trend_up/trend_dn 腿 = **OPT4_VolatilitySystem 多空信号原样 import**（冻结 2.0/2.0/0.8 门/60d 时间止损/1% 风险/2x 杠杆；反向信号离场永不门控）；range 腿 = v1 内联 4h 布林 z-rejection meanrev（冻结值原样）。**申报变体 3 个，路由策略为唯一差异**：

| 变体 | 入场路由 | 风险 scale | regime 离场 |
|---|---|---|---|
| A 否决+分级 | 多头放行 {up,range}，空头 {dn,range}（仅否决逆向趋势；v1 iter-11 模式移植） | 对齐趋势 1.0x / range 0.5x | 逆向趋势确认即离场 |

| C 静态对照 | 全部非 turbulent 态放行 | 恒 1.0x | 无（纯信号/止损/时间离场） |

- **池内无增量**：A 变体利润保留仅 **9.0%**（135.04/1495.8），且 DD 反而更高（17.33% > 15.92%）；C 保留 59.1% 但 DD 28.47% 超标。Router20A Sharpe 1.14 略高于 OPT4 单体 1.01（波动更低），但 Calmar 13.58 < 组合 19.658。**在主池上，任何形式的 regime 门控都在削 OPT4 的利润而不改善 DD。**

## 5. 结论与灭因

1. **Router20A 过研究级门槛**——池内 +135.04%/DD 17.33%、新币 +18.49%、全面优于 v1 同宇宙基线。但**相对静态 sleeve 无池内增量**：立线价值不在替代组合，而在新币/扩展宇宙的稳健化。
2. **灭因档案**：
   - v1 骨架（EMA 腿版）：宇宙扩展即死（12p −6.08%/11p −17.97%）——"唯一 OOS 为正的架构"是 3 币+顺风窗的局部现象，非可迁移优势；
   - B 严格槽位路由：池内平庸、新币 −24.4%——趋势态仅占 ~10% 时间，槽位门控饿死突破引擎并让 MR 腿（已证死重）占满仓位；
   - v1 meanrev 腿：所有变体/宇宙零到负贡献，2.0 中纯死重；
   - C 静态对照：证明池内利润损失来自 turbulent 暂停本身（暂停入场也暂停了高波动期的修复盈利），池内 DD 反而恶化。
3. **Router 骨架去留**：**保留为"turbulent 暂停 overlay"，不作全路由组合层**。可迁移、被新币轴证实的组件只有 turbulent 态（+ C 形态：OPT4 信号 + 暂停 + 无 trend 路由）；趋势槽位/分级 scale 只在愿意用 91% 池内利润换 DD 控制时才有意义（A 形态，对应部署宇宙外的扩展场景）。若后续做宇宙扩展线，建议先测"C 形态暂停 overlay"而非完整 Router。
4. 局限：本轮未跑 lookahead-analysis/delay-1（策略为两个已验证冻结组件的原样组合，信号→执行同烛次开语义与 v1/OPT4 一致，regime 序列因果性由构造保证并经 v1 诚实 OOS 间接检验）；阈值扰动压力（regimes_thr_hi/lo）仅有 3 币序列，未纳入 23 币矩阵。
